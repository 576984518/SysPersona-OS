## 范围

这一版回答两个问题：**这套东西怎么和一个具体的第三方客户端配合（以及怎么再加一个）**，以及**出事时怎么降、降到哪、怎么看得见**。

- 新增 `docs/CLIENT_ADAPTER.md`——客户端接入契约：一个客户端 = 一段配置（`img` 认进程、`wm` 找水位、
  `actions` 定能做什么、`open` 定会话在哪）；**自动操作客户端的六种方法**（界面注入 / 调试口 / 命令行 /
  只重启内核 / 拉起网关 / 进程动作）及各自前置条件与失败样子；加一个新客户端的五步。
  示例**只给 Hermes**（CN 桌面版）：内核 `:9120` 健康检查、调试口发 `/compact`、网关独立进程、会话在
  `hermes-home`。
- 新增 `docs/RESILIENCE.md`——容灾降级：三条原则（先保通路、降级必须可见、断网也能跑才算容灾）；
  四层降级（进程 / 配置 / 模型 / 通道）；模型链 `paid → cloud → local` 与余额阈值；断网代班卡；
  恢复顺序（网关 → 内核 → 窗口 → 重读）；七组开关；**已知风险**（自动换档没做完、`dr` 默认关）。
- 参考实现入库：`tools/tray/persona_tray_clients.py`（配置驱动 + 动态二级菜单 + 版本比对）、
  `tools/tray/persona_hermes_kernel.py`（只重启内核，不关窗口）。

## 证据

- Hermes 示例里每条操作都在本机实测过：内核重启 **21 秒**完成且 `GET /api/health` 返回 `{"ok":true}`；
  压缩/重读走调试口返回 `SENT`；网关独立进程用 `gateway status` 判活、`VBS` 隐藏拉起；
  版本读到桌面 exe `0.9.0.0` + 内核 `0.21.0-cn.18`（`manifest.json`）。
- 降级链的阈值是这台机器上的实际口径（DeepSeek < ¥5、硅基 < ¥1），不是估算。
- 已知限制也写在文档里：自动换档未完成、`dr` 开关默认关闭、客户端升级后适配要人做。

## 边界

- **不修改、不重打包第三方客户端**；不点它的界面按钮（能命令行/接口就不碰界面）。
- 平台仅 Windows 10/11，无 Linux/macOS 实现，不依赖云服务。
- 容灾的**自动**模型换档没有交付，只做到"判定 + 提示 + 换一份可替换配置"；文档里明确写着，不冒充完成。
- 托盘那一侧的规格重写属于 **5.1 线**（`docs/TRAY_SPEC.md`），不占本版编号。
