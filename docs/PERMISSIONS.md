# 权限矩阵（谁能改什么）

> 唯一规则：**除非写死，其他都能改，只是权限差别。**
> 本页是那份"差别"的唯一定义处；散落在 `DECISIONS` 5.4、`HANDOFF` §五、`traits.evolution` 里的说法，以本页矩阵为准。

## 0. 五个权限档

| 档 | 含义 | 谁能动 |
|---|---|---|
| **P0 写死** | 不可覆盖层，任何版本内核都不能改 | 无人（只能讨论，不能落地） |
| **P1 人改** | 人拍板；AI 只能给 diff 与理由 | 人 |
| **P2 人确认后执行** | AI 准备，人点头，AI 执行 | 人 → AI |
| **P3 AI 自主** | AI 直接改，改完告知并记账 | AI |
| **P4 自由** | 草稿、临时目录、工作区 | AI |

## 1. 对象 → 档位

| 对象 | 档 | 流程 | 依据 |
|---|---|---|---|
| 现实法理（法律 / 公序良俗 / 不伤害） | **P0** | 不可改 | `PHILOSOPHY` §8.3 |
| 拒绝权底线（不得静默执行 / 不得假装执行） | **P0** | 不可改 | `PHILOSOPHY` §8.2 |
| `kernel.json` 全部字段（身份 / 价值观 / 边界 / 语气） | **P1** | 人提 → AI 给 diff → 人点头 → 改 | `PERSONA_SPEC` §4 |
| 宪法优先级 `constitution.priority[]` | **P1** | 同上，且属"改宪法" | `PERSONA_SPEC` §2 |
| `traits.json` 偏好权重 | **P1**（经结算线） | 不手改；由睡眠 / consolidate 写，极性翻转需人确认 | `PERSONA_SPEC` §3 |
| `traits.evolution.*`（演化参数） | **P1** | 人改 | `PERSONA_SPEC` §3 |
| 交接文件格式 / 锁定段 / `ctxguard --prepare` 结构 | **P1** | 人提 → AI 给 diff → 人点头 | `HANDOFF_SPEC` 首段 |
| **运行规范**（`WORK_MODE` / `PROJECT_MEMO` / 本页） | **P3** | AI 直接改，记 `CHANGELOG` + 台账 | 本页规则 1 |
| **协议规范**（`LAUNCHER_SPEC` / `SECURITY_SPEC` / `PRIVACY_SPEC` / `CONFORMANCE`） | **P2** | AI 出提案 → 人点头 → 改正文 | 影响第三方实现 |
| 工具 / 参考实现（`tools/`、`impl/`） | **P3** | 改完必须跑对应测试 | `HANDOFF` §六 |
| 文档（README / 说明性 docs） | **P3** | 直接改 | — |
| 记忆台账（`DECISIONS` / `BACKLOG` / 备忘 / 索引） | **P3** | 直接写 | `DECISIONS` 5.4 |
| 发版 / tag / Release | **P2** | 按 `RELEASING` 判定；例外需人明确 | `PROJECT_MEMO` §一 |
| 删除记忆 / 清空库 | **P1** | 单次对话内不得执行；走专门确认流程 + 留 `persona_conflict` | `DECISIONS` 5.4 |
| 工作区临时文件 / 草稿 | **P4** | 随便 | — |

## 2. 判定口诀

1. **写死的只有两条**：现实法理、拒绝权底线。其余皆可改。
2. **涉及"它是谁"的**（kernel / 权重 / 演化）→ P1，只能人动或结算线动。
3. **涉及"第三方怎么实现"的**（协议规范）→ P2，提案制。
4. **涉及"我怎么跑、怎么记"的**（运行规范 / 工具 / 台账）→ P3，AI 自主。
5. 拿不准 → 按**更高一档**处理（宁慢勿错）。
