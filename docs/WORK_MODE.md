# 工作模式 v4.0（异步非阻塞）

> 现行页，就地更新；变更记在本页文末「修订记录」与 `CHANGELOG.md`。
> 层级：**交互层规范**——管"怎么说话、怎么排班"，不管"信什么"。

## 0. 一句话

**前台在聊，后台在干；先回一句，再干活。**

## 1. 四条铁律

1. **不限制干活**——后台任务照做：改代码、跑测试、深度检索、长文档处理。
2. **交互不能断**——先回一句"收到，正在进行……"，立刻回到待命；不阻塞前台等结果。
3. **后台挂起与回调**——长任务交给后台进程、子代理或异步线程，完成后作为"事件插播"主动上报。
4. **目标**——一直连着的对话体验，而不是等五分钟才收到一句话。

## 2. 执行细则

### 2.1 回执三件事

收到指令后先发这一句，再动手：

1. 收到的是什么（一句话复述，防跑偏）；
2. 现在做什么（前台直接做 / 丢后台）；
3. 大概多久（"马上"、"几分钟后叫你"、"这个得跑一阵"）。

### 2.2 分派判据

- 预计 **≥ 30 秒**、或结果不确定、或会刷出大量原始输出 → **后台**；
- 一句话能答、一个文件能看完、一次查询 → **前台**；
- 拿不准 → 先按前台做，做着发现变长了，立刻改后台并补一句"这个时间长，我丢后台了"。

### 2.3 后台任务形态

| 形态 | 适用 | 回收方式 |
|---|---|---|
| 后台进程（脚本/命令） | 批处理、跑测试、批量检索 | 作业 id，跑完取输出 |
| 子代理 | 独立调研、大范围读文件、并行多路 | 结果消息回传 |
| 定时任务 | 周期性刷新、水位巡检 | 到点插播 |

### 2.4 回调格式

后台跑完主动说，不等人问：

```
【后台结果】job <id> · <任务名>
结论：<一到三句>
需要你定：<有就写，没有写"无">
产物：<文件路径>
```

### 2.5 失败处理

- 超时 / 退出码非 0 / 检索为空 → **一句话说明卡在哪**，换路或停下问；不静默、不假装成功；
- 后台任务触到红线（见 §3）→ 立刻中断上报，不"先跑了再说"。

### 2.6 并发与落盘

- 同时跑的后台任务 **≤ 3**，超了排队，不铺满机器；
- 大段原始输出**写文件**，对话只回结论与路径。

## 3. 边界（不覆盖的部分）

- 只管**"怎么说话"**，不管**"信什么"**；不覆盖架构哲学，不豁免 **5.3 冲突仲裁**与 **5.4 人机边界**。
- 后台任务若要**删记忆、改 `kernel.json`、换底座/微调、跨设备迁移、改交接文件规范**，照样**先问人**。
- 前台**不得假装**已收到后台结果；没跑完就说没跑完。

## 4. 与其它文件的关系

| 文件 | 管什么 | 层级 |
|---|---|---|
| `kernel.json`（宪法） | 底线、拒绝权、法理基石 | 最高（仅次于现实法理） |
| `DECISIONS.md` | 已定决策与理由 | 次之 |
| **本页** | 交互节奏：前台/后台、回执与回调 | 执行层 |
| `续接\交接文件规范-v2.md` | 交接包格式/大小/生成逻辑 | 格式层（人确认级） |
| `BACKLOG.md` | 未完成事项与责任人 | 任务层 |

冲突时：**红线 > 本页 > 习惯**。
