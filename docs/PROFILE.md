# 画像生成（PROFILE）

> **SysPersona-OS** · 本文件定义：画像：从记忆里长出来的偏好与习惯，怎么生成、怎么用
> 规范全文以仓库 `main` 为准；改了要同步 README / CHANGELOG / 台账。

> 一句话：**画像不是一个模型"觉得你是什么人"，而是一串可追溯的观察。**
> 状态：v5.1.0 起为默认链路；实现在 `tools/ctxpack/persona_daemon.py`。

## 一、两个文件，两种真相

| 文件 | 写什么 | 谁写 |
|---|---|---|
| `memory\USER.md` | 对人的观察，一条一行，带日期与证据 | 对话里的"记一条观察：…"被自动收割 |
| `memory\MEMORY.md` | 当下事实：架构、模型、版本 | 人改，或由决策落定后同步 |

壳侧（Hermes / 未来任何壳）自己的 `memories\` 目录只放**指针**：≤ 2000 字符，指向上面两份。
这样壳换了，画像不用重写。

## 二、采集：不靠模型自觉

```
对话里说「记一条观察：他讨厌反复确认」
        ↓  persona_bridge 导出时扫描（harvest）
- [2026-11-09] 他讨厌反复确认 → 证据：Hermes 会话
        ↓  persona_daemon 的 merge 任务
memory\USER.md 的 OBSERVATIONS 段（只追加）
```

规则：

1. **只认固定句式**（`记一条观察：` / `记条观察：`），避免把闲聊当画像；
2. **只追加**，写过的观察不重写；
3. 同一句已在文件里就跳过——合并是幂等的，跑一百次也只进一条；
4. 收割失败的原文留在 `sessions\`，可以人工补。

## 三、生成：便宜模型干这件事

| 槽位 | 模型 | 为什么 |
|---|---|---|
| `auxiliary.profile_describer` | 免费档 `Qwen/Qwen3-8B` | 只是把已有观察归纳成一段话，不需要判断力 |
| `auxiliary.title_generation` | 同上 | 同一类输出型任务 |

**判断型任务不许用免费小模型**（工具选择、审批、任务拆解），见 `DECISIONS.md` 十一。

## 四、边界

- 画像**不是**得分、不是打分表，是一串带证据的句子；
- 删除任何一条观察都要人确认（`5.4 人机边界`）；
- 画像里不许出现密钥：入口文件会被 `mask_secrets` 扫一遍，命中只报不改。

## 五、验收

| 判据 | 怎么验 |
|---|---|
| 收割生效 | 说一句"记一条观察：…"，下一轮 `merge` 日志出现「并入 1 条」 |
| 幂等 | 同一句说两遍，`USER.md` 只多一行 |
| 可追溯 | 每条观察都带 `[日期]` 与「→ 证据」 |
| 不越权 | 断开壳之后，`USER.md` 仍是判断依据——画像不依赖任何客户端 |
