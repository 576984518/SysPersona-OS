# 寄生在开源壳上的记忆层（v5.0.0）

> 这一版不是加功能，是**换活法**：停止自研客户端，把记忆层嫁接到成熟的开源壳上。

## 一、为什么改路线

自研客户端最贵的不是功能，是**壳**：沙箱、权限确认、UI、升级、跨平台。
这些东西既不产生记忆价值，又要持续吃维护成本——而且一旦壳出问题（权限弹窗、登录态丢失），
记忆链路跟着一起断。

2026-11-09 验证了另一条路：**壳用现成的，记忆层自己拿住**。

## 二、三条落地

### 1. 架构脱身：接入开源壳

- 壳：Hermes Agent 中文社区桌面版（Electron 前端 + Python 运行时，本地 `state.db` 是 SQLite + FTS5）。
- 记忆层仍是纯文件：`D:\4590-PC-文件\AI会话检索记录`（`sessions/` + `archive/` + `index/`）。
- 壳不托管记忆，只**读**记忆：它的工具直接读我们的文件，两边不绑定，随时能换壳。

### 2. 免费双核路由：本地检索 + 云端大脑

- **大脑**：免费平台（OpenAI 兼容接口）的免费档，`Qwen/Qwen3.5-4B`（256K 上下文，11 月实测 2.7–7.7 秒/轮，
  工具调用正常）。重活仍交给网页端 DeepSeek。
- **检索**：本地 `bge-m3`（免费、1024 维、约 0.4 GB），增量索引 2525 块用 8.5 分钟、**0 tokens**。
- 分工原则：embedding 与 rerank 留在本地（不花钱、不出门），对话大脑走云端免费档。

### 3. 底层物理突破：路径映射绕开小模型缺陷

4B 级模型在**中文长路径**上会插入空格：实测把 `AI会话检索记录` 输出成 `AI 会话检索记录`，
于是工具报 `File not found`，看起来像权限问题，其实只是 tokenization。

解法是 Windows 目录联接（Junction，不需要管理员权限）：

```powershell
cmd /c mklink /J C:\hermes-mem "D:\4590-PC-文件\AI会话检索记录"
```

之后一律让它读 `C:\hermes-mem\LATEST.md`——纯 ASCII、无空格，一次就中。

## 三、证据

| 项 | 实测 |
|---|---|
| 工具调用 | `read_file` 0.4 秒，读出归档 1098 条，报告内容与 `LATEST.md` 一致 |
| 一轮开销 | 42.6 秒 / 38.6k 输入 token（含工具说明） |
| 工具面裁剪 | 31 组 → 11 组（`platform_toolsets` 白名单） |
| 免费校验 | 价格页机器可读数据：`Qwen3.5-4B` 输入/输出均为 0；`Qwen2.5-7B` 同为 0 但仅 32K，被壳的 64K 门槛拒绝 |
| 索引成本 | 本地 `bge-m3` 嵌 2525 块 = 0 tokens / 8.5 分钟 |

## 四、边界（别当成品）

- **数据出本地**：大脑在云端，发给它的内容都离机；上云前必须先过脱敏（`impl/launcher/mask_secrets.py` 七条规则）。
- **免费档有限流**：RPM/TPM 触发 429 是常态，批量活不要压在免费档上。
- **壳的升级会打回原形**：`config.yaml` 之外的补丁（如工具白名单）在壳升级后要重放；工具白名单已写成配置，可重放。
- **登录态仍未解决**：壳读网页会话那条链路依旧要手动扫码，和 v4.3.0 记录的问题同源。
