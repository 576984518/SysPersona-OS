## v5.3.0 — 保活 + 交互代理（待做）

**保活**：监控智能体进程，卡死或未运行就拉起；记录拉起原因与次数。

**交互代理**：智能体里的 AI 通过本程序调用本机系统（脚本、文件、进程）。

**定时唤醒的完整动作链**（关键，不只是"拉起来"）：

```
唤醒 → 重读总索引（所有来源汇总） → 知道后面发生了什么
     → 再连后台服务 → 看有什么能做 → 认领任务
```

**索引分两层**：
- **总索引**：所有来源（各客户端、各分身、各设备）汇成一份，回答"全局发生过什么"；
- **分索引**：每个来源各有一份，回答"这条具体来自哪"。
唤醒后**先读总索引**，再决定做什么；不读索引就认领 = 盲干。
