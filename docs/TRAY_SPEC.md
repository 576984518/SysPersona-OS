# 托盘状态显示 — TRAY_SPEC

> 状态：**v5.2 实现已落地（2026-11-10 重写）**，代码 `tools/tray/persona_tray.py`。
> 原名「托盘（控制台）设计」，2026-11-10 改名为**托盘状态显示**——它现在不是「灯」，是一块
> 常驻的状态板：**几个客户端在跑，就并排显示几个，各自带各自的水位**。
> 这份文件回答三件事：托盘是什么、显示什么、怎么保证不打扰人。

## 一、定位：状态显示 + 控制台，不是智能体

托盘是 **SysPersona-OS 的配套状态板**，用来看着第三方智能体程序（DSH / Hermes / 以后换的壳）在不在跑、
水位到哪。

它不承载对话，不做推理，不跑本地模型。它只做三件事：**看得见、点得动、退得掉**。

## 二、它不自己调模型

**已否决**：托盘内置小模型自己去执行任务。
理由：多一个模型依赖，多一份显存/内存占用，还会和主节点的路由打架。

正确的是路由模型：

```
托盘（状态板）
   └─ 指定一个主节点（主记忆分身 / 某个具体记忆分身）
        └─ 主节点按「能力 + 可用性」把任务派给某个分身
             └─ 完成 → 结果回到主节点 → 回给托盘
                   └─ 该分身掉线 → 主节点自动切到下一个可用的
```

**谁来做，由主节点决定**；托盘只负责把「要什么」和「结果」端到端接好。

## 三、图标规范（v5.2 定稿）

> 2026-11-10 定：**同心圆嵌套不可取**——图标本来就小，多套几圈没法看。改成方块并排。

- **一个客户端一个正方形，从左到右并排**（n 个客户端 → 画布等分 n 个正方形）；
- **只画正在运行的客户端**，没运行的不显示，也不占位；
- 正方形边框颜色 = 该客户端水位等级：绿 `<35%`、黄 `≥35%`、红 `≥80%`（或守护异常）；
- 正方形内部从底部往上填充，填充高度 = 该客户端水位百分比；
- 没有水位源的客户端（Cherry / Cursor 之类）只画空框，表示「在跑，但测不到水位」；
- 0 个客户端 → 一个灰色空框，不显示数字、不报警。

| 客户端数 | 图标 |
|---|---|
| 1 | 一个满尺寸正方形 |
| 2 | 两个正方形并排 |
| 3–4 | 边长自动缩小（64/n），仍并排 |

## 四、水位来源（分开取，不混）

| 客户端 | 来源 | 频率 | 过期 |
|---|---|---|---|
| DSH | `persona_gauge.py`（读 cost-meter 账本） | 60 秒 | 测不到就显示「在跑」 |
| Hermes | 守护写出的 `ops/hctx.json` | 随守护 | 超过 10 分钟视为过期、不用 |
| 其他壳 | 暂无 | — | 只显示「在跑」 |

悬停提示一行并列：`SysPersona · DSH 123K/1.0M 12% · Hermes 125K/1.0M 12%`。
菜单「状态」：逐客户端一行 + 守护各任务最近一次结果。

## 五、不弹窗铁律（2026-11-10 踩坑后定）

托盘是 `pythonw`（GUI 子系统，**没有控制台**）。它再去 spawn 控制台程序（`tasklist` / `node` /
`cmd` / `powershell` / `clip`），Windows 会给子进程**新建一个黑色控制台窗口**，屏幕上就是一闪一闪。

规矩：

1. 托盘里所有 `subprocess` 调用一律带 `creationflags=0x08000000`（`CREATE_NO_WINDOW`）；
2. 被托盘调用的脚本（如 `persona_gauge.py`）**内部**再 spawn 时同样要带——统一用
   `persona_win.py`：`import persona_win` 即生效（它替换 `subprocess.Popen`，`run/call/check_output` 全覆盖）；
3. 托盘自己**必须**用 `pythonw.exe` 启动，用 `python.exe` 会留一个常驻黑窗（2026-11-10 实踩）。

## 六、边界

- 不写记忆、不改索引、不碰 `ops/*.json` 以外的数据；
- 不做界面注入、不替换字体；
- 不内置模型、不直连 API；
- 状态来源只有两处：守护的 `ops/persona-status.json` + 各客户端自己的水位源（见 §四）。

## 七、失败时的行为

| 情况 | 托盘表现 |
|---|---|
| 状态文件缺失 | 灰色空框，不报错、不重试 |
| 守护进程死了 | 标题加「守护异常」，**托盘不负责拉起**（那是看门狗的活） |
| 某任务 `ok=false` 但属设计如此（如 `agent` 只报不拉） | **不算故障**，白名单 `BENIGN_FAIL` 里 |
| 客户端进程不在 | 该格不画，标题里也不出现 |
| 主节点掉线 | 由主节点侧切到备用分身，托盘只显示「已切换」 |

## 八、开机自启

`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\SysPersona-Tray.lnk` →
`pythonw.exe tools\tray\persona_tray.py`。

自检：`pythonw persona_tray.py --probe` 只打印一帧状态然后退出（不进托盘），用来验证数据源通不通。
