# 进化史（EVOLUTION）

> 一句话：**这不是功能清单，是「我们改过哪些主意」。**
> 版本细节见 `CHANGELOG.md`；为什么这么定见记忆库 `DECISIONS.md`。

## 一、三个阶段，两次转向

```
v3.x  把设计跑起来            （自研客户端：壳、内核、记忆、检索）
  │
  ├─ 转向一：停止自研客户端 ─────────────────────────────┐
  │   理由：客户端本身就是最大的不确定项，而记忆才是资产。 │
  ▼                                                      │
v4.x  把规范与工具做扎实       （人格/交接/权限/抓取/索引）│
  │                                                      │
  ├─ 转向二：记忆层寄生到开源壳上 ───────────────────────┤
  │   理由：壳可以换、记忆不能丢；把"能不能读"变成"读得多快"。│
  ▼                                                      ▼
v5.0.0 落地：Hermes 作主力，DSH 降冷备
```

## 三、被否掉的主意（比做成的更值得记）

| 当时的想法 | 结论 | 为什么 |
|---|---|---|
| 自研客户端（Vault、Cordis 插件、M1–M4 分层） | 停 | 客户端是最大不确定项，记忆才是资产 |
| 强制对齐 / 微调压制底座性格 | 废 | 换来的是顺从，不是人格 |
| 控制台闪烁上 Cordis 插件 | 不做 | 为少闪几个窗口写常驻 hook，维护成本高于收益 |
| 兜底模型用 4B 保智商 | 改 | 3.2G 权重 + 大上下文在 16G DDR3 上必爆，兜底只为不失联 |
| 把州目录 junction 进同步范围 | 否 | `state.db` 带 WAL，被同步抓走会拿到半截快照 |
| 上下文压缩手动触发 | 暂缓 | 延迟工具的嵌套参数，DeepSeek 系模型填不出 |
| 只改几句话就发版 | 禁止 | 版本号是承诺，不是日志 |
