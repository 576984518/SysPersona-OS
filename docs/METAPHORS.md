# 比喻与联想索引

这份文档把对话里出现过的比喻**逐条**收进来，按主题归类。每一条保留原话（或原话的连续片段），并注明它在方案里对应的技术概念。

说明：

- 收录范围：从「上下文耗尽了」这一句开始，到对话后段关于启动器、UUID、加密、恢复、云端回写的部分。
- 只删掉了 AI 的吹捧与自我夸赞（「太绝了」「军师」「封神」之类），**比喻本身一条未删**。
- 「出处」中的编号是对话消息编号；标「对话后段」的，是你后来补充、当时分享快照里还没有的部分。
- 同一比喻在对话中反复出现的，只在首次出现处收录，并在备注中说明复用。
- **术语注（2026-11-10）**：本页保留原话；原文里的「人格」「漂移」是当时的说法。现行口径是——重载=重置，只谈记忆分身（规则+记忆+现场），「漂移」只指长会话里规则失焦（自然漂移），权重 / 特征演化称「权重演化」。见 README「它解决什么」一节末。

## 这些比喻各自对应了哪个设计决策

比喻不是修辞装饰。上表里至少有一半直接变成了方案里的结构：

| 比喻 | 落成的设计 |
|---|---|
| C 盘 / D 盘 / 内存 | 设定文件（只读）／长期记忆（可检索）／工作上下文（易失）三层分离 |
